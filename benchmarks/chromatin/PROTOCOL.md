# Human peak caller comparison

Protocol fixed on 1 November 2026 before producing or scoring calls. Use biological replicates 1 and 2 from each experiment in the manifest. These are isogenic cell-line culture replicates. Select GRCh38 chr1, chr19 and chr21 in advance to include a large autosome and smaller chromosomes with contrasting gene density. Conclusions apply to this regional panel of conventional bulk assays. Whole-genome testing and primary human tissues are separate validation scopes.

Use released ENCODE filtered genomic alignments. Retain primary MAPQ ≥30 alignments and exclude duplicate, supplementary, unmapped and QC-failed records. For ATAC, take one fragment per properly paired, same-contig template with positive insert length ≤2 kb. Use the complete fragment for each caller. For histone ChIP, use single-end tags and a fixed 200 bp fragment setting. Remove input intervals that cross a GRCh38 assembly gap or hg38 blacklist-v2 region. Within each experiment equalize the two treatment replicates to the smaller eligible chromosome-panel count with exact seeded sampling. Preserve the actual regional abundance across chromosomes. For ChIP, pool the precise input BAMs listed as parents of the ENCODE fold-enrichment tracks. Split this pool by seeded random assignment into calling and evaluation halves so the counts used to evaluate enrichment are withheld from both callers.

ATAC compares MACS2 2.2.7.1 and MACS3 3.1.0 callpeak in paired-fragment mode at q=0.05 with the HMMRATAC implementation in MACS3 3.1.0. Fit HMMRATAC independently by replicate using its default enrichment thresholds and fixed training seed. Evaluate its accessible cores with nucleosomal flanks excluded. Compare MACS3 broad calls (strong q=0.05, broad cutoff 0.10) to Omnipeak 1.6.6883 with its default FDR and model, matched input, 200 bp fragment setting and the same study mask. Retain all eligible reads after the common filters. Calculate the MACS effective genome size from the unmasked length of the three chromosomes. Fold/signal estimates and FDR thresholds of different methods have different interpretations.

Use 100 bp bins for ATAC and 1 kb bins for ChIP. Exclude bins touching the mask. Native calls select bins whose midpoints lie in a peak. Report called bases, width distributions, replicate Jaccard and the fraction of bins covered. For ATAC, the independent reference is the intersection of both matched-cell ENCODE DNase 0.001 peak sets, scored at bin midpoints. Report precision, recall and F1 against this proxy. For ChIP, score enrichment of held-out replicate tags in the selected bins relative to the withheld control tags, normalized by each library's eligible tag count. Use tag centers shifted along their strands by half the common fragment length.

To compare callers at equal coverage, within each replicate and chromosome retain as many called bins as the smallest caller covers. Rank each caller's bins using the same training signal: ATAC fragment midpoints in a five-bin window or ChIP treatment/input normalized counts in a five-bin window. Break ties deterministically. The held-out replicate and DNase reference do not enter the ranking. This is a standardized evaluation view, not a production peak set. Report matched-coverage metrics together with the native calls and domain widths.

The existing baselines are MACS2 for ATAC and MACS3 broad mode for broad-mark ChIP. For a regional recommendation to switch ATAC caller, require at least 0.02 absolute improvement in mean matched-coverage DNase F1 in **each** cell line with no drop in matched-coverage replicate Jaccard exceeding 0.02 in either line. For a given histone mark, require at least 10% improvement in mean matched-coverage held-out enrichment in **each** line, with the same Jaccard tolerance. Treat missing or empty calls, inconsistent direction between cell lines, and pronounced contrary native or chromosome-level performance as reasons for review before switching. These are operational margins chosen for this benchmark, not formal significance tests. Do not treat bins, chromosomes, or overlapping intervals as independent patients.
